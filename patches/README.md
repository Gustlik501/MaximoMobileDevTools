# patches/

Generated by `mdt diff`: one unified diff per tree, OOTB -> CUSTOMIZED
(`framework.patch`, `techmobile.patch`, ...), with paths relative to the tree.
They are reports for review ("what did we change in IBM's code?"); the
source of truth is CUSTOMIZED itself. `mdt upgrade` doesn't use them. It merges
from OOTB at the last commit, OOTB now and CUSTOMIZED.

Commit them if you want the diff visible in pull requests.
